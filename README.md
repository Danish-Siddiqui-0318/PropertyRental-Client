# AD Property Rental — Frontend

Web frontend for the AD Property Rental platform: browse listings, request rentals, manage properties, payments and admin tools.

## Development

```sh
npm i
npm run dev
```

Set `VITE_API_URL` to the backend address (defaults to `http://localhost:5000`). See `INTEGRATION.md` for backend setup notes.

## Built with

- TanStack Start, React, TypeScript
- Tailwind CSS
